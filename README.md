# javascript-lotto-precourse

## 🛠️ 기능 구현

-   입력 흐름
    -   구입 금액 입력을 받는다. (1,000원 단위의 정수)
    -   당첨 번호 입력을 받는다. (1,2,3,4,5,6 쉼표 구분, 6개 정수)
    -   보너스 번호 입력을 받는다. (정수 1개, 당첨 번호와 중복 불가)
-   로또 발행
    -   로또 1장 가격은 1,000원이다.
    -   구입 금액 / 1,000 만큼 로또를 발행한다.
    -   각 로또는 1~45 범위의 중복 없는 6개 숫자를 가진다.
    -   발행된 번호는 오름차순 정렬하여 출력한다.
-   당첨 판정
    -   사용자가 입력한 당첨 번호 6개와 보너스 번호 1개를 기준으로 각 로또를 비교한다.
    -   일치 개수 및 보너스 일치 여부로 등수를 결정한다.
        -   1등: 6개 일치 / 2,000,000,000원
        -   2등: 5개 일치 + 보너스 일치 / 30,000,000원
        -   3등: 5개 일치 / 1,500,000원
        -   4등: 4개 일치 / 50,000원
        -   5등: 3개 일치 / 5,000원
-   통계 출력
    -   총 수익률 = (총 당첨금 / 총 구매 금액) × 100
    -   소수점 둘째 자리에서 반올림하여 출력한다.

## 예외 상황

-   1,000원으로 나누어 떨어지지 않는 경우 → [ERROR] 구입 금액은 1,000원 단위여야 합니다.
-   숫자가 아니거나 빈 입력/음수/0 → [ERROR] 구입 금액 형식이 올바르지 않습니다.
-   개수가 6개가 아닌 경우 → [ERROR] 당첨 번호는 6개여야 합니다.
-   숫자가 아니거나 공백만 있는 토큰 포함 → [ERROR] 당첨 번호 형식이 올바르지 않습니다.
-   범위(1~45) 밖의 값 존재 → [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
-   중복 번호 존재 → [ERROR] 당첨 번호에 중복이 있습니다.
-   숫자가 아니거나 빈 입력 → [ERROR] 보너스 번호가 올바르지 않습니다.
-   범위(1~45) 밖 → [ERROR] 보너스 번호는 1부터 45 사이여야 합니다.
-   당첨 번호와 중복 → [ERROR] 보너스 번호가 당첨 번호와 중복입니다.
-   출력 형식을 지키지 않으면 0점 처리 (문구, 쉼표, 괄호, 하이픈, 줄바꿈 등 예시와 동일해야 함)
-   예상치 못한 오류 발생 시 → [ERROR] 출력 중 문제가 발생했습니다.
